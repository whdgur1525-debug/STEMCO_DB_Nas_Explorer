Synapse NAS Explorer 0.3.7 — 연결·전체 검색·요청 시 집계

C# WPF Windows x64 프로그램. VS2022에서 AOI-NasExplorer.sln을 열어 직접 수정할 수 있습니다.
개발 호환: .NET9 / 런타임 포함 배포: .NET10. 빌드 스크립트는 PowerShell7 tools/Build.ps1.
NAS PostgreSQL 조회만 사용하며 Handler/Vision/장비동작/다모/MES/복제를 실행하거나 변경하지 않습니다.

0.3.5에서 추가된 기능
- '모델 또는 LOT'은 한 검색어를 두 필드 중 어디에서든 찾는 OR 검색입니다. 예제와 실제 DB를 동일하게 맞췄습니다.
  모델·LOT을 함께 제한하려면 상세 검색의 정확한 모델 / LOT 두 칸을 사용합니다. 검색 방식별 도움말도 전환됩니다.
- 같은 목록의 F5/추가 읽기에서 열 정렬을 유지합니다. 체크와 열람 항목은 원본 ID로 복원하며 정렬은 현재 표시분 기준입니다.
- 내보내기 창에서 선택 반출 범위와 화면 검색 합계를 구분합니다. 현재 패널은 단일 검사 메타데이터를 읽어
  패널 번호·검사 Index·불량 전체 건수를 미리 보여줍니다. 읽기 시점이 달라 최종 저장 수량이 바뀔 수 있습니다.
- Bar_result / NO_DB / _검사이력의 밑줄을 실제 화면과 접근성 이름에도 그대로 표시합니다.
- 이미 확인한 ERT 모델 미지원 사유는 옵션 옆에 안내합니다. 이미지 저장은 독립 선택할 수 있으며,
  이 안내를 위해 전체 모델 DB를 추가로 스캔하지 않습니다. 미확인 모델의 지원을 보장하는 표시도 하지 않습니다.
- 체크 이미지 결과에 완료·취소됨·일부 실패와 '선택 N개 중 저장 M'을 표시합니다. 부분 파일과 기록은 보존합니다.
- 이전 0.3.4와 새 0.3.5는 각각의 실행본 ZIP을 별도 폴더에 모두 풀어 사용하세요. 두 폴더의 DLL을 섞지 마세요.
찾고 확인하기
- 연결할 때는 서버의 DB 이름만 읽습니다. 선택한 DB의 검사 스키마는 검색할 때 확인합니다.
- DB를 고르고 LOT 또는 모델 이름 일부로 검색합니다. 전체 DB를 찾을 때는 범위에서 '전체 DB 검색'을 선택하세요.
- 전체 검색은 찾은 결과부터 표시합니다. '계속 조회'로 뒤의 DB 또는 다음 페이지를 읽습니다.
  시간 초과·권한 오류 등으로 확인하지 못한 DB는 작업 기록에 남습니다. 해당 DB만 선택해 다시 검색할 수 있습니다.
- 모델 → LotID → Layer 전체 이름 → 패널 검사 → 불량 순서로 열 수 있습니다.
- 표 바로 위 파란 경로에 검색 방식 / Model(...) / LotID(...) / Layer(...) / 패널을 표시합니다.
  표 아래로 도구 버튼을 모았으며, 열람 중인 행은 파랑, 체크한 행은 초록으로 구분합니다.
- Layer는 L1/L2만으로 합치지 않습니다. 전체 이름과 프로파일·해상도 코드 0150/0200/0250를 구분합니다.
  T/B는 방향 코드, L1/L2는 레이어 코드로 표시합니다. 이름 코드로 실측 해상도 단위를 임의 추정하지 않습니다.
- 고정한 Model/LotID/Layer는 위 경로에 표시하고 목록에서 반복하지 않습니다. 미선택 범위는 열을 유지합니다.
- LotID는 사람이 쓰는 LOT 문자열입니다. 내부 DB lot_id 키는 Index로 표시합니다.
- PC를 기본 목록에서 숨겼습니다. 현재 INLINE은 Handler가 pc_no=0 검사 ID를 만들고 여러 Vision이 공유합니다.
  원본 PC 값과 검사 Index는 상세에 보존합니다. 과거의 다른 검사 ID를 임의 병합하지 않습니다.
- 뒤로/앞으로와 Alt+방향키, 검색 결과 경로 복귀를 제공합니다.
- 상세에서 뒤로 가거나 '검색 결과'로 돌아오면 최근에 읽은 목록·정렬·체크를 복원합니다.
  복원한 목록의 마지막 조회 시각은 목록 아래 안내에서 확인할 수 있습니다.
- 새로고침/F5는 현재 목록을 갱신합니다. 새 검사 DB를 찾으려면 탐색 옆 ↻를 누르세요.
  명시적으로 고른 DB 하나는 새 DB가 생겨도 전체 DB로 확대하지 않습니다.
- 연결 창에서 비밀번호 암호화 저장을 체크하고 연결하면, 같은 Windows 계정으로 재시작해도 체크와 비밀번호가 복원됩니다.

체크와 내보내기
- 목록 맨 위 체크박스로 현재 표시분을 전체 체크/해제합니다. 부분 체크는 중간 표시로 구분합니다.
  중복된 상단 체크/해제 버튼은 제거했습니다. 체크박스 열은 가로 스크롤에도 고정됩니다.
- 불량 목록 오른쪽에 원시 X/Y, CAD 원본 X/Y, ERT 정수 CAD X/Y, 유닛 X/Y, 원본 축 X/Y를 표시합니다.
  ERT 정수 CAD는 소수 부분을 버린 값이며 DB 원본 소수 좌표도 별도로 유지합니다.
- 현재 목록 전체 체크는 읽힌 목록만 대상입니다. 검색 전체는 내보내기 창에서 별도로 선택합니다.
- 체크 개수를 누르면 이전 표시 구간의 항목까지 모아서 확인·검색·개별 해제할 수 있습니다.
  변경은 적용할 때 반영합니다. 새로고침/F5는 현재 체크를 유지하고, 이전 목록으로 돌아갈 때는 그 목록의 체크를 복원합니다.
- 패널·장비 조건을 바꾸면 이전 검사 Index 제한을 해제하고 변경 조건으로 다시 조회합니다.
  새 검색은 탐색하던 폴더 제한을 풀되 새로 바꾼 상세 Model/LotID/Layer 값은 반영합니다.
- 조건 초기화는 선택한 DB를 유지합니다. 새 연결에 성공하면 이전 연결의 조건·체크·원본 Index를 초기화합니다.
- 작은 창에서는 상세 조건과 경로에 스크롤을 제공하고 조건 적용 후 상세 입력을 접어 목록을 확보합니다.
- 중앙 내보내기에서 체크 범위/검색 전체/현재 불량 패널 전체를 선택합니다.
  기본 체크는 ERT와 불량 이미지 두 개입니다.
  Bar_result(NO_DB 폐기 바 .txt), Defect Point(NO_DB 패널별 불량 집계 .txt)는 각각 직접 보이는 선택 옵션이며 기본은 꺼져 있습니다.
  추가 자료를 펼치면 불량 건수 CSV/불량 상세 CSV/기타 NO_DB 파일/과거 검사 포함을 선택합니다.
  불량 건수 CSV는 패널별불량수.csv와 바별검출수.csv이며, Defect Point TXT와 별개입니다.
  불량 상세 CSV는 각 패널 폴더의 불량목록.csv입니다.
- 모델·LOT·Layer 체크는 폴더 전체 의미입니다. 날짜·장비·패널·불량 조건으로 그 폴더의 내용을 자르지 않습니다.
  검색 전체는 원래 검색조건으로 부모 항목을 먼저 정하고, 해당 부모의 모든 패널을 저장합니다.
  특정 날짜/패널만 저장하려면 패널 검사 목록에서 해당 검사들을 체크합니다.
- 불량 한 건의 현재 패널 전체를 선택하면 해당 검사 ID의 전체 불량·이미지를 저장합니다.
- Handler 기본 폴더: 장비/Model/LotID/Layer/018.ERT, 장비/Model/LotID/Layer/18/원본이미지명.png.
  SEMCO 순서(장비/Model/Layer/LotID)도 선택 가능합니다. ERT 파일명만 3자리, 이미지 폴더는 정수입니다.
- 기본은 ERT+이미지이며, 장비/Model/LOT/Layer/패널별 최신 검사만 저장합니다.
  특정 검사 Index를 체크하면 해당 기록을 그대로 저장합니다. 과거 검사 포함 옵션은 _검사이력에 추가합니다.
- 기본 반출 폴더에는 ERT와 PNG만 들어갑니다. 불량 건수 CSV/불량 상세 CSV/기타 NO_DB 파일은 별도 선택입니다.
- 조건·처리내역·원본 추적 정보는 %LOCALAPPDATA%/Synapse/NasExplorer/ExportHistory에 보관합니다.
  원본 스냅샷은 변환이 끝나면 정리하고, 실패·취소 시 원본과 진단 정보를 이 PC에 보존합니다.
- 대상 확인을 누르면 실제 대상 검사 수와 Model/LOT/Layer 목록을 먼저 확인합니다.
  검색 전체, 여러 패널 체크 범위 또는 100개 이상이면 범위 확인 체크 후 시작합니다. 진행 게이지와 중지/상세 기록을 제공합니다.
- 이미지 미기록은 개별 원본 ID와 사유를 기록합니다. 실패·취소 결과와 부분 파일은 보존합니다.
- 원본 JSON/현재 목록 CSV/ERT 미리보기는 목록 우클릭 메뉴에서 사용할 수 있습니다.
- 불량 목록 우클릭의 '체크한 불량 이미지 저장'은 체크한 이미지들만 저장합니다.
  중앙 내보내기의 '체크한 불량이 속한 패널 전체'와 구분합니다. 열람 이미지 위 우클릭으로 한 장도 저장합니다.
- Bar_result는 Bar_result_<LOT>.txt입니다. NO_DB의 Panel No,MaskingBar와 MES 번호 규칙을 사용합니다.
  마스크 0은 헤더만 생성하며, NULL·현재 모델과 맞지 않는 마스크는 정상으로 추정하지 않고 사유를 남깁니다.
- Defect Point는 Defect Point_<Model>_<LOT>_<Layer>_<레이어>_<공정>_<장비>.txt입니다.
  NO_DB 16열 형식이며 ERT 칸은 선택 검사 전체의 DB 불량 행수입니다. ERT 파일 저장 여부와 무관합니다.
  DB에 기록되지 않은 Handler eq/vms/autoPass/NG·판정은 빈칸으로 보존합니다. 같은 DB 행수를 세 칸에 복제하지 않습니다.
  Total은 선택 범위이며 과거 검사 포함 시 같은 패널의 재검 기록도 누적합니다. T/T는 기록된 Handler T/T의 평균입니다.
  Handler T/T 미기록을 별도 스캔시간으로 대체하지 않습니다. 해상도는 현재 모델 DB 기준, 조회 불가 시 공란입니다.
  집계 파일 선택만으로 ERT·이미지·CSV·폐기 마스크·펀치 파일이 함께 생성되지는 않습니다.
- 기타 NO_DB 파일은 별도 선택입니다. DB 폐기마스크는 block_dispose.txt로, 확인된 펀치 증거는
  Layer/punch.json으로 모읍니다. Bar_result 옵션과 독립입니다.
  현재 Layer 재검 표식은 과거 RETEST.INI로 만들지 않고 이 PC의 진단 기록에만 보관합니다.

실시간 수집과 함께 사용하기
- 기본은 수동 갱신입니다. 자동은 1분 또는 5분에 분산 대기를 더하고 이전 조회가 끝난 뒤부터 셉니다.
- 자동 갱신은 이미 확인한 현재 조회 범위를 갱신합니다. 새 검사 DB의 발견은 탐색 옆 ↻를 사용합니다.
- 비활성 화면, 검색조건 편집, 체크한 항목, 추출 중에는 자동 갱신으로 작업을 덮지 않습니다.
- 앱을10분 사용하지 않으면 자동 갱신을 끄고 조회 연결을 정리한 뒤 '이전 목록으로 돌아가기' 화면을 표시합니다.
  이 버튼으로 직전 목록을 바로 복원하고, 최신 결과가 필요할 때 F5를 누르세요.
  내보내기 중에는 완료/취소까지 기다립니다. 연결·내보내기 설정과 파일 선택 대화상자는 작업 중으로 봅니다.
  재개해도 자동 갱신은 꺼진 상태입니다. 사용자가 필요할 때 다시 켭니다.
- DB 연결은 앱당 동시2개, 같은 DB당1개로 제한합니다. 유휴 풀은 최대2개/DB당1개입니다.
- 내보내기 시작 때 대상 검사 ID를 고정하고 패널별 읽기 스냅샷을 로컬에 저장합니다.
  이미지 원본은 패널 단위 연속 조회로 읽으며, 임시 자료는 저장 목적지와 별개로 이 PC의
  %LOCALAPPDATA%/Synapse/NasExplorer/ExportSpool 아래에 둡니다. 실패·취소 시 보존 위치는 결과 JSON에 기록합니다.
  DB 연결을 반환한 뒤 PNG 등 파일을 만듭니다. 패널끼리는 읽은 시각이 다를 수 있습니다.
  작업 중 새 검사는 다음 내보내기에 포함됩니다. 미처리 패널의 새 판정·불량은 그 패널을 읽는 시점에 반영됩니다.
  NAS 수집이나 Handler/Vision 처리를 멈추지 않으며, 패널별 기준시각은 출처·처리내역에 남깁니다.

건수·재구성의 의미
- 상단 불량 합계는 화면의 250개가 아닌 검색 전체 저장 기록 수입니다. 재검도 별도 기록으로 포함합니다.
  'LOT · 패널별 전체 건수'를 펼쳐 '전체 건수 조회'를 눌렀을 때만 합계를 계산합니다.
- LOT별/패널별 집계 표는 DB별 최대1000개를 표시합니다. 전체 합계에는 이 한도를 적용하지 않습니다.
- 화면 열 정렬은 현재 표시분 기준입니다. 목록은5000개 구간으로 넘기며 추출에는 표시 한도가 없습니다.
- ERT 양식은 VisionPlatform Data Transfer의 2026-11-05 변경(7989f97, 최신 cd9dca1) 기준입니다.
  V/B/P 앞 공백, 줄 끝 쉼표와 공백, CRLF, UTF-8(BOM 없음), reserved 0, 숫자 G15 표기를 일치시켰습니다.
  유효한 소수좌표는 유지하고 소수점 뒤 불필요한 0만 생략합니다.
  일반 ERT area는 0, 확인된 펀치만 9999입니다. DB defect_size 실측값은 상세/CSV에 유지합니다.
- ERT는 DB 재구성본이며 과거 원본 파일 다운로드가 아닙니다.
- 모델 DB는 rawModelName + _Layer + 전체Layer명으로 조회합니다. 다른 레이어의 모델 좌표를 재사용하지 않습니다.
- 모델 DB/원래 검사 설정이 없으면 정확한 ERT를 보장할 수 없습니다. 이미지·CSV는 독립 저장할 수 있습니다.
- Header 유닛수/분할축/해상도는 현재 모델 기반 재구성이며 Handler 당시 open_short_GM/분할/원본 모델과
  다를 수 있습니다. 보정 내용과 출처를 이 PC의 ExportHistory에 보관합니다.
- 실제 검사 당시 재검 회차/바폐기/eq 원본총수 등이 DB에 없으면 0/OK로 지어내지 않습니다.
  NO_DB의 모든 부가 파일이 정확하게 재생성된다고 주장하지 않습니다. 독립 검토와 보완 진행 중입니다.

예제와 로컬 체험
- 예제의 모델/LOT/Layer 명칭은 회수 자료 기준입니다. 수량·좌표·이미지는 연습용이며 실제 검사 결과가 아닙니다.
- --demo는 예제, --local은 저장 호스트가127.0.0.1/localhost/::1일 때만 자동 연결합니다.
- 실제 회수 DB 체험과 예제는 구분합니다. 회수본 전체는 LOT15/검사103/불량257902입니다.
- 연결 비밀번호 저장은 현재 Windows계정 DPAPI입니다. %LOCALAPPDATA%/Synapse/NasExplorer에 설정·로그를 둡니다.
- 기존 PostgreSQL 서비스/운영 NAS는 테스트 대상으로 임의 조작하지 않습니다.
